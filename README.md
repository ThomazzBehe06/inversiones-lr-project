# Inversiones LR
## Accommodation-Marketplace

A frontend to browse, filter, get quotes for, and simulate bookings of short-term accommodations.

## Main Features
- Interactive catalog of active properties displaying photos, location, property category, capacity, rates, guest reviews, and key amenities
- Advanced search controls to filter by location, property type, guest count, price range, and score, plus a quick filter-reset feature
- Comprehensive property details page including description, house guidelines, user feedback, photo gallery, interactive map, and local weather updates
- Automated stay calculator showing price breakdown: nights, subtotal, cleaning cost, 10% platform fee, and total sum
- Booking simulation module paired with a dedicated "My Bookings" tracking interface
- User authentication suite with simulated sign-up and sign-in functionality
- Navigation bar currency converter powered by live exchange rate integrations

# Installation
```bash
git clone https://github.com/ThomazzBehe06/inversiones-lr-project
cd inversiones-lr-project
npm install
npm start
```

## Running the app:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`.
